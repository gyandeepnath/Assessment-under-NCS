# tooling

Build, CI, and scaffolding — not shipped to devices.

| Folder | Role |
|---|---|
| `ci/` | CI gates: lint, unit tests, Tier-A simulation recovery, validation report checks. |
| `module-scaffold/` | Generator for a new conformant module (standard layout + Module Conformance Suite template). |
| `schema-codegen/` | Generate types from the versioned data schema (`data-layer/src/schema/`). |
