# Scientific Specifications

Canonical, versioned scientific specs — one per module construct. A module names the spec
it implements in its manifest (`specVersion`) and must not change a spec's meaning once
released (new science = new spec version; see ARCHITECTURE §12).

| Spec ID | Construct | Implementing module | Status |
|---|---|---|---|
| `PVANC-1.0-SPEC` | Presenting visual acuity (non-clinical conditions) | `acuity-pvanc` | place `PVANC-1.0-SPEC.md` here |

Naming: `<SPEC-ID>.md` (e.g. `PVANC-1.0-SPEC.md`).
