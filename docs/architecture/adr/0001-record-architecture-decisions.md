# 0001 — Record architecture decisions

- **Status:** accepted
- **Date:** 2026-06-21

## Context
Architecture decisions need a durable, reviewable trail as the platform grows.

## Decision
Record significant decisions as numbered ADRs in `docs/architecture/adr/NNNN-title.md`.
The platform architecture itself is specified in `docs/architecture/ARCHITECTURE.md`.

## Consequences
Future structural changes reference or supersede an ADR rather than relying on memory.
