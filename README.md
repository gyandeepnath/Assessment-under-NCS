# Assessment-under-NCS

Modular psychophysics-based vision assessment platform (smartphone, tablet, desktop,
and similar displays).

## Documentation

- **[Platform Architecture Specification](docs/architecture/ARCHITECTURE.md)** — high-level
  architecture, repository structure, module/plug-in contract, shared engine, calibration
  and quality-control engines, data model, simulation and validation layers, API boundaries,
  error handling, versioning, assumptions, and risks.

The first concrete module implements the **PVANC-1.0-SPEC** (Presenting Visual Acuity Under
Non-Clinical Conditions). The scientific specification is the canonical reference for that
module.

> Status: design phase — architecture and contracts only, no implementation yet.
